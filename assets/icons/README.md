# Icon sources

Vendored for the interactive service architecture diagram on the homepage.

- **AWS Architecture Icons** — [awslabs/aws-icons-for-plantuml](https://github.com/awslabs/aws-icons-for-plantuml) (`dist/` PNGs). AWS icon usage terms apply.
- **Brand marks** — [Simple Icons](https://simpleicons.org/) SVGs (CC0 1.0). Azure DevOps comes from `simple-icons@9`, since it is no longer in the current set.

Service-kind mappings used by the diagram live in `assets/site.js` (`qcIcons`). Keep the filenames stable when updating icons.
