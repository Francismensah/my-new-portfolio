// postmortems

        
Things that broke, and what fixed them

        

          Real classes of failure from a production fleet. The unglamorous ones
          teach the most.
        

        

          

              PM-01SEV · NGINX
            

            
Fixing the Nginx 502 Bad Gateway

            

              SYMPTOMUpstream sent too big header during a production
              login outage.
            

            

              FIXAdjusted proxy buffer configuration across affected
              services.
            

          

              PM-02SEV · EDGE
            

            
Cloudflare 522 caused by an EC2 public IP change

            

              SYMPTOMAn instance restart changed the origin IP and broke
              the edge connection.
            

            
FIXMoved the origin to a stable Elastic IP.

          

              PM-03SEV · SYSTEMD
            

            
A decommissioned service ruined an Easter holiday

            

              SYMPTOMAn old service restarted after reboot, stole the
              port, and crashed its replacement.
            

            
FIXProperly decommissioned the systemd unit.

          

              PM-04SEV · LINUX
            

            
The reboot that took us down

            

              SYMPTOMProduction services failed to return cleanly after a
              server reboot.
            

            

              FIXHardened units, logs, timers, release flow, and
              rollback.
            

          

              PM-05SEV · CULTURE
            

            
Writing postmortems that drive real change

            

              SYMPTOMBlameless reviews that documented failure without
              changing the system.
            

            

              FIXUsed timelines, root cause analysis, and action items
              that actually ship.
            

          

              PM-06SEV · SCALE
            

            
Building scalable and elastic infrastructure

            

              SYMPTOMStatic infrastructure could not safely absorb
              changing traffic.
            

            

              FIXUsed AMIs, launch templates, Auto Scaling, ALB, and
              Cloudflare at the edge.
