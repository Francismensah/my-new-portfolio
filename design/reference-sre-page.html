Things that broke, and what fixed them

  
Real classes of failure from a production fleet. The unglamorous ones teach the most.

  

    
PM-01SEV · DB
Migration blocked on lock contention
SYMPTOMEF Core migration hung on a PostgreSQL ALTER TABLE.
FIXFound the competing lock and sequenced the migration around it.

    
PM-02SEV · IAM
Uploads failing on a missing S3 permission
SYMPTOMInventory API errors on presigned uploads.
FIXClosed the IAM gap, then added Cloudflare WAF bypass rules for the presigned endpoints.

    
PM-03SEV · APP
Type mismatch took out an API endpoint
SYMPTOMNpgsql InvalidCastException in production.
FIXTraced DateTimeOffset vs timestamp mismatch to the schema.

    
PM-04SEV · SEARCH
Client and server disagreed on what "Elasticsearch" is
SYMPTOMUnsupportedProductException from the NEST client.
FIXIdentified the OpenSearch incompatibility and moved to a compatible client path.

    
PM-05SEV · SCALE
ASG rollout hit a security group limit
SYMPTOMAPI scale-out blocked by a rule cap.
FIXRestructured security group rules to fit within limits.

    
PM-06SEV · POOL
Connection pool exhaustion in a consumer
SYMPTOMNpgsql pool at its 100 cap, 30s timeouts.
STATUSInvestigating the repository call path holding connections.
